# 📊 Interactive Ecommerce Sales Analysis Dashboard in Excel

📊 Ecommerce Sales Analysis Dashboard
📌 Project Overview

This project presents an Interactive Ecommerce Sales Analysis Dashboard built in Microsoft Excel using Power Query, Pivot Tables, Pivot Charts, Slicers, KPI Cards, and Data Visualization techniques.

The dashboard analyzes 9,994 ecommerce orders and provides valuable insights into sales performance, profitability, customer segments, product categories, and regional trends to support data-driven decision-making.

🎯 Business Objective

The objective of this dashboard is to:

Monitor overall business performance
Track Sales, Profit, Orders, and Quantity
Identify top-performing product categories
Analyze monthly sales and profit trends
Evaluate regional and state-wise performance
Enable interactive filtering for deeper analysis

🔍 Key Insights
1. Sales & Profit Performance
Sales and profit showed consistent growth throughout the year.
Highest sales were recorded during the last quarter (October–December).
December generated the highest monthly revenue.
2. Category-wise Profit Analysis
Technology generated the highest profit of $145K.
Office Supplies contributed $122K profit.
Furniture generated the lowest profit of $18K.
3. Category-wise Sales Share
Technology contributed 37% of total sales.
Office Supplies contributed 32%.
Furniture contributed 31%.
4. Top Performing Subcategories

The highest revenue-generating subcategories were:

Phones – 25.53%
Chairs – 25.41%
Storage – 17.32%
Tables – 16.01%
Binders – 15.74%
5. Geographic Analysis
California emerged as the top-performing state.
Significant sales concentration was observed in major metropolitan regions.
